# Landing Page — Catálogo 140 Looks Prontos

Crie uma landing page premium para o **Catálogo 140 Looks**, um catálogo digital de looks prontos para copiar.
O design deve ser **feminino, sofisticado e acolhedor** — transmitindo praticidade e elegância.

**Idioma:** Português brasileiro (PT-BR)
**Mobile-first:** A página deve ser otimizada para mobile, já que a maioria do tráfego vem de redes sociais.

## NOTAS IMPORTANTES DE IMPLEMENTAÇÃO

### Mobile-First
- A página deve ser projetada primeiro para mobile (375px)
- Breakpoints: 640px (sm), 768px (md), 1024px (lg)
- Todas as seções devem funcionar bem em coluna única

### Performance
- Lazy load para imagens abaixo do fold
- Otimizar GIF do app (pode ser pesado)
- Usar `loading="lazy"` em imagens

### Animações
- Usar Intersection Observer para animações no scroll
- Preferir CSS animations sobre JS quando possível
- Animações suaves (ease, ease-out) — nada abrupto

### Acessibilidade
- Contraste adequado (especialmente texto branco sobre rosa)
- Botões com hover/focus states claros
- Alt text em todas as imagens

### Whitespace
- Generoso espaçamento entre seções
- Nunca parecer "apertado" ou poluído
- Respiração visual é essencial para o tom sofisticado

### Cores
- Primary (#C41E7A) usado com moderação — CTAs, badges, destaques
- A maioria do texto é dark sobre light
- Seções escuras para criar contraste e ritmo visual
